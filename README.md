# Bad Piggies Mod

Add-on for Bad Piggies vehicles in Minecraft Bedrock

## Features

- Rideable Green Pig entity with seat component
- Wooden and iron frames for vehicle construction
- Super glue for attaching frames and other components

## Requirements

- Minecraft Bedrock Edition (1.20.0 or later)

## Installation

1. Download the `.mcaddon` file from the releases section.
2. Open Minecraft Bedrock Edition.
3. Go to `Add-Ons` in the settings.
4. Click on the `+` button and select the downloaded `.mcaddon` file.
5. Enable the add-on and start playing.

## Usage

1. Craft wooden frames using wooden planks.
2. Spawn Green Pig entities to ride them.
3. Use super glue to attach frames and other components to the Green Pig entities.

## Configuration

The add-on does not have any configuration files. All settings are hardcoded within the add-on.
